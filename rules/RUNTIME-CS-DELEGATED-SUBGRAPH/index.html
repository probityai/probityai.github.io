RUNTIME-CS-DELEGATED-SUBGRAPH

A delegation-event hop in a multi-hop A2A delegation DAG (a hop that declared it spawned a delegated task) declares a delegated sub-graph root that no hop in the ingested trace produced: the delegated sub-tree the check depends on is absent, so the composition-safety delegation check cannot soundly evaluate the delegated branch. A coverage-completeness gap (surfaced as a per-check notApplicable, never a silent clear) rather than a confirmed exploit: a masked delegated sub-tree may be a benign framework boundary or may mask a colluding delegator that withheld a child branch it spawned, so the missing delegated sub-graph is surfaced for investigation. The delegation twin of RUNTIME-CS-JOIN (a missing downstream sub-tree vs a missing upstream causal parent). The topology walk reads the delegator's FORWARD delegated_task_ids declarations against the task_id set the chain produced. It deliberately does not key off upstream references: a whole-subtree mask erases the child, so nothing points back at it, and only the delegator's surviving forward declaration can witness the mask.
