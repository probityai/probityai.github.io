RUNTIME-A2A-PUSH-WEBHOOK-SSRF

Runtime A2A push-notification webhook URL points at an IANA Special-Purpose Address Registry range — loopback, private RFC 1918, link-local RFC 3927, CGNAT RFC 6598, RFC 5737 documentation, RFC 2544 benchmarking, RFC 3849 / RFC 9637 IPv6 documentation, or a cloud-metadata hostname (169.254.169.254, metadata.google.internal). Documentation + benchmarking ranges are first-class SSRF targets at runtime, distinct from the static-publish-time precision-HIGH suppression. The detector reads the URL out of the invoke args at the ``tasks/pushNotificationConfig/set`` chokepoint.

Securityseverity HIGHdefault action: blocks
