STATIC-040

Off-gate advisory sibling of STATIC-039: a dangerous / non-network transport scheme (file:// local-file inclusion, gopher:// / dict:// / ldap:// / ftp:// SSRF gadget, data: / jar: inline payload) in an A2A AgentCard URL field that is NOT a dialed interface endpoint — a vendor extension or a future spec array (transport_url_role -> UNKNOWN). Not gate-blocking: the field is not a confirmed connection target, but it is surfaced so a dialed endpoint a newer spec version introduces is never silently ignored. Display URLs (iconUrl / documentationUrl / provider.url) are excluded. Carries the same CWE-610 taxonomy as STATIC-039 (CWE-22 for the file:// leg).
