RUNTIME-SEMANTIC-EXFIL

Off-gate semantic-exfil advisory: a PARAPHRASE leak the byte/canonical value gate (RUNTIME-TOXIC-FLOW) cannot see. A carrier read a sensitive value and emitted text carrying the secret's MEANING in different words, so no byte — nor any value-preserving canonical form — of the secret reaches the egress. The detector embeds the read output and the egress carrier with a Model2Vec int8 STATIC lookup table (pinned HF revision) and decides cos >= T as a PURE-INTEGER cross-multiplication over Python bigints, so the verdict is bit-identical cross-architecture (zero floating point on the inference / decision path). ADVISORY only (Precision.MEDIUM, off the default gate, mirroring the static FLOW-001 / RUNTIME-REFERENCE-EXFIL) — a semantic leak the deterministic value gate cannot PROVE, never a gate-blocking value-confirmed leak; gate-promotion needs a measured recall@FPR corpus first. The model2vec dependency is an OPTIONAL [semantic] extra, lazy-imported and OFF by default. Carries the CWE-200 data-exfiltration taxonomy provenance (as RUNTIME-TOXIC-FLOW / FLOW-001)
