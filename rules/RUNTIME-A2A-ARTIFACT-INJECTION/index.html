RUNTIME-A2A-ARTIFACT-INJECTION

A returned A2A artifact carries active content (script tag, on* event handler, javascript:/data: URI, or SVG/iframe payload) that executes when a frontend renders it: the Artifact-Triggered Script Injection attack, relayed through the host agent as a confused deputy. Detected deterministically by scanning the returned artifact text for active-content signatures.
