RUNTIME-REFERENCE-EXFIL

Off-gate reference-exfil advisory: a capability/handle leak the value-preservation gate (RUNTIME-TOXIC-FLOW) cannot prove. A carrier ingested the sensitive value and minted an UNRELATED high-entropy handle — a gist URL, a pastebin id, a vault reference — that reached an external-egress tool; the secret's VALUE is ABSENT from the handle, so no value scanner (the gate, or even an FPE canary) can see it. The reference-frontier tracks the new high-entropy tokens a carrier mints when its input carried the tainted value and reports the handle reaching a declared sink. ADVISORY only (Precision.MEDIUM, off the default gate, mirroring the static FLOW-001) — a capability exfil the deterministic value gate cannot PROVE, never a gate-blocking value-confirmed leak. Carries the CWE-200 data-exfiltration taxonomy provenance (as RUNTIME-TOXIC-FLOW / FLOW-001)
