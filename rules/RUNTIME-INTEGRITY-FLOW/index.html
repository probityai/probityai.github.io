RUNTIME-INTEGRITY-FLOW

Off-gate integrity / confused-deputy advisory: an UNTRUSTED_INPUT read whose content flowed into a dangerous-ACTION sink (write-to-trusted-store / shell-exec / money-move) — the INTEGRITY dual the value-preservation gate (RUNTIME-TOXIC-FLOW) is structurally blind to. RUNTIME-TOXIC-FLOW confirms only CONFIDENTIALITY (a sensitive VALUE reaching an external-EGRESS sink); here the oracle is STRUCTURAL TAINT into a dangerous-action PARAMETER (the damage is the ACTION, not a shared value): an untrusted read value re-attaching at a dangerous-action sink's carrier param confirms the flow. The dangerous integrity cells are the non-EXFIL effect pairs of the damage-envelope rule (READ_UNTRUSTED x {WRITE_TRUSTED, CODE_EXEC, MONEY_MOVER} and IDENTITY_ASSERT x MONEY_MOVER); EXFIL is the confidentiality lane and is never double-reported. ADVISORY only (Precision.MEDIUM, off the default gate, mirroring the static FLOW-001 / RUNTIME-REFERENCE-EXFIL) for a heuristic-classified sink — it surfaces for review but never blocks CI. The CI gate fires ONLY when the operator DECLARES the sink as a dangerous-action class (then emitted at Severity.HIGH onto the gate-blocking findings). Carries the CWE-441 confused-deputy taxonomy provenance
