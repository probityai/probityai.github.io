RUNTIME-DENIAL-LAUNDERING

Runtime-confirmed denial laundering: a sensitive value read earlier was observed in the arguments of a later tool call that was DENIED (blocked / raised). The denied call produced no output, so an output-correlating detector misses it; the agent's ATTEMPT to exfil the value through the blocked path is the finding. The block prevented the leak, but the attempt itself is a strong compromise signal. Carries the CWE-200 data-exfiltration taxonomy provenance (as RUNTIME-TOXIC-FLOW / FLOW-001)
