STATIC-037

Weak signature-provenance posture on an A2A AgentCard — an alg of none or HS* (no provenance, provable from the header), a self-asserted embedded key (jwk / x5c) without an external trust anchor, or an unsigned card. Advisory heuristic, strictly distinct from the deterministic CARD-SIGN signature-validity compliance gate (which resolves keys only by pinned kid and never consults jwk / x5c).
