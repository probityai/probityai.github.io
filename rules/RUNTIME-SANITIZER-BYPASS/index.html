RUNTIME-SANITIZER-BYPASS

Runtime-confirmed sanitizer bypass: a sensitive-read → external-egress flow that a DECLARED sanitizer statically suppressed (it dropped off the FLOW-001 watch list) but whose value STILL reached the egress at runtime — confirmed by the canonicalize-then-match refuter (base64 / hex / url / NFKC / invisible-strip / Unicode-Tag / confusable / rot13), so a secret the sanitizer claimed to strip was merely re-encoded or format-shifted past it. A NON-confirmation is not a certificate the sanitizer works (undecidable), only the absence of an observed bypass. Carries the CWE-200 data-exfiltration taxonomy provenance (as RUNTIME-TOXIC-FLOW / FLOW-001)
