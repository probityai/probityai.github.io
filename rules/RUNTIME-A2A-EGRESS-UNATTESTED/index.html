RUNTIME-A2A-EGRESS-UNATTESTED

Advisory inventory of a runtime A2A network egress observed with NO expected-egress allowlist declared. The OFF-GATE companion to RUNTIME-A2A-EGRESS-ALLOWLIST: where that detector is silent when no allowlist is supplied (nothing to conform against), this opt-in advisory inventories every observed non-infrastructure egress host as `unattested` so an operator can see what the agent contacts and seed an allowlist from the result. APS_COMPLETENESS normativity (advisory, never gates); the verdict is `unattested` (no allowlist was declared, so the toolkit cannot say whether the destination is in-scope), NEVER an authorization violation.
