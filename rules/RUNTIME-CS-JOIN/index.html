RUNTIME-CS-JOIN

A join / fan-in hop in a multi-hop A2A delegation DAG references a causal-parent task that no hop in the ingested trace produced: one of the parents the join depends on is absent, so the composition-safety join check cannot soundly evaluate the fan-in. A coverage-completeness gap (surfaced as a per-check notApplicable, never a silent clear) rather than a confirmed exploit: a dropped parallel branch may be a benign framework boundary or may mask a colluding intermediary that erased a branch, so the missing causal parent is surfaced for investigation. The topology walk reads only the task_id / reference_task_ids DAG off the ExecutionResult chain.
