RUNTIME-OUTPUT-REFLECTION

Off-gate indirect-prompt-injection reflection advisory: an UNTRUSTED INPUT's value reappears INSIDE an ACTIVE output markup position (a markdown image src, a markdown link href, an HTML src=/href= attribute, or an injection-delimiter position). This is a PROVENANCE signal — untrusted data crossing into an active output slot — ORTHOGONAL to the presence-based markdown-exfil scan (INJECTION-MARKDOWN-EXFIL / assert_no_injection), which flags dangerous markup regardless of where the URL came from: a static safe ![x](http://cdn) produces nothing here, a reflected evil.example/{stolen} in an image src fires. The reflected value can arrive encoded, so each untrusted input is expanded via the value-preserving canonical_forms transcoder (base64/hex/URL/Unicode) before the active-markup substring test. Native + deterministic (regex + canonical_forms; no model, no LLM, no floating point). ADVISORY only (Precision.MEDIUM, off the default gate, mirroring the static FLOW-001 / RUNTIME-SEMANTIC-EXFIL) — a reflection signal for review, never a gate-blocking value-confirmed leak; gate-promotion needs a measured recall@FPR corpus first

Securityseverity MEDIUMdefault action: reports
