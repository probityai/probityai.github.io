RUNTIME-RENDER-SINK

Tool output or agent-card text carries a payload a chat interface renders as an active sink: a Mermaid click or link directive or init block, a markdown image or link whose URL carries a query string to another origin, or raw HTML with a script, frame or event handler. A plain diagram or a static link produces nothing
