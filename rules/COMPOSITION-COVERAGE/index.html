COMPOSITION-COVERAGE

Composition-coverage gap (advisory test-generation driver, NOT a security proof): a dangerous capability-class co-activation reachable by the declared toolset lacks a generated flow-test. The bounded-combinatorial damage-envelope driver (security._coverage_proof) lowers each tool to a fixed, small set of capability CLASSES, enumerates the 2^N-2 damage-envelope cells (N = the class count, a constant independent of toolset size — never the path-enumeration blow-up over tool subsets), keeps the dangerous co-activations the toolset can reach, and lists which lack a generated flow-test as test-generation targets. Coverage over capability classes does NOT imply a real exploitable flow exists; the finding is an advisory checklist gap, never a verdict. Emitted inline and off the default CI gate by construction (not a DetectorRule on iter_default_gate)
