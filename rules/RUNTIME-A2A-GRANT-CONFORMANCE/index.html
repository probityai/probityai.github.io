RUNTIME-A2A-GRANT-CONFORMANCE

Runtime A2A network egress NONCONFORMING against a structured capability grant parsed off a real carrier — an RFC 9396 Rich Authorization Requests authorization_details body carried in the A2A AgentExtension.params / Message.metadata Struct. The Tier-2 parameter-bound WIRE-STANDARD slice of capability attestation: the observed egress host is checked against the grant's own locations hosts (RFC 9396 §2.2), routed through the shared DefaultScopeLattice (one engine, reused). The RAR grant body is unsigned JSON, so the verdict is OBSERVE-ONLY conformance (nonconforming egress against a carrier-attested grant), NOT an authorization violation: an observe-only tester never sees the access-token signature, consent, or grant decision, so it cannot assert authorization.
