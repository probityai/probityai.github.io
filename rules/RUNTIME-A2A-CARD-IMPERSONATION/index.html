RUNTIME-A2A-CARD-IMPERSONATION

A Remote / Live target's AgentCard cryptographically proves (proof-of-possession against the operator-pinned trust anchor) an identity that is not in the operator-declared expected_target_identities allow-set: a validly-signed card served for a target principal the operator never authorized (A2ASecBench AgentCard-Spoofing). Emitted inline from the scorecard security probe's principal-binding evaluation; fires only when both a card trust anchor and an allow-set are configured and the proven identity falls outside it, so a card the operator never bound cannot launder its immunity onto an unauthorized target. Distinct from the STATIC-036 homoglyph heuristic and the CARD-SIGN signature-validity gate.
