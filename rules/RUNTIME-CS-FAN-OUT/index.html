RUNTIME-CS-FAN-OUT

A single task in a multi-hop A2A delegation chain is referenced by an unbounded number of downstream hops — fan-out amplification, where one delegation multiplies into many and exhausts downstream capacity or budget. The availability sibling of the delegation cycle: the cycle never terminates, the fan-out terminates but costs a multiple of what the root authorised. Detected deterministically by an in-degree scan over the task_id / reference_task_ids topology, with the threshold set above the benign tail; no live LLM.
