Reference verifier: agent-evidence-verify

This URI identifies the reference verifier agent-evidence-verify, the distribution of the probity repository's packages/agent-evidence-verify. A decision, bundle or conformance run it writes carries this identifier in the verifier member. Each decision also carries the installed version and the package digest, so the URI names the verifier and the version names the release.

The identifier was minted with release 0.5.0 and does not change. Releases 0.1.0 to 0.4.1 were published as probity-verify and carry https://probityai.github.io/probity/verifiers/probity-verify; the current verifier reads records that name either one.
