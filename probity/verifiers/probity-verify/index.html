Reference verifier: probity-verify (predecessor identifier)

This URI is the verifier identifier that releases 0.1.0 to 0.4.1 of the reference verifier carried, when its distribution was named probity-verify. Bundles and decisions those releases wrote keep it, so it never stops identifying them. From release 0.5.0 the verifier writes https://probityai.github.io/probity/verifiers/agent-evidence-verify and still reads this one.

Source: packages/agent-evidence-verify.
