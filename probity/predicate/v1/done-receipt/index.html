Predicate type: done receipt

This URI is the predicate type the reference verifier and the admission policies read on a done receipt: an in-toto Statement v1 whose predicate is a done receipt, with the isolation facts the verifier harness writes at the end of the grading run in predicate.verifier_isolation.

The specification of the done receipt is published at https://probityai.github.io/agent-evidence/predicate/v1/done-receipt (the persistent identifier https://w3id.org/agent-evidence/predicate/v1/done-receipt resolves there). The isolation facts a verifier adds are described in the admission package's verifier-isolation guide. This URI is written into signed bytes and does not change.
