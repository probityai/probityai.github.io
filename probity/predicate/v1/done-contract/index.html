Probity

Predicate type: Done Contract

Type URI:

https://probityai.github.io/probity/predicate/v1/done-contract

Version 0.1.0. Status: draft, self-hosted predicate type URI.

Purpose

States, before an agent's first turn, what "done" means for one task: which paths the agent may not change, which commands a separate verifier will run, and how well those commands tell a fix from a no-op. The contract is sealed by whoever starts the agent, so an outside verifier can check the agent's claim of completion against it. The contract carries no verdict; verdicts belong to the Done Receipt.

Model

The subject is the contract record, by digest: exactly one member whose digest holds exactly one entry, sha256, equal to the SHA-256 of the bytes of the probity-done-contract/v1 record. The predicate is that record as a JSON value, and a verifier refuses the statement if the predicate differs from the parsed record. predicateType must equal the type URI above.

Schema

{
  "_type": "https://in-toto.io/Statement/v1",
  "subject": [
    { "name": "contract.json", "digest": { "sha256": "<64-hex of the record bytes>" } }
  ],
  "predicateType": "https://probityai.github.io/probity/predicate/v1/done-contract",
  "predicate": {
    "schema_version": "probity-done-contract/v1",
    "contract_id": "contract-app-1",
    "task": "make test_app pass",
    "protected_paths": [
      { "path": "tests", "kind": "directory", "exclude": ["__pycache__"],
        "sha256": "<tree digest of the files under tests>" }
    ],
    "acceptance": [ { "id": "unit", "argv": ["python", "-m", "pytest", "-q", "tests"] } ],
    "adequacy": { "mutants": 4, "killed": 3 }
  }
}

Verification rules

A verifier applies these in order and reports the first that fails.

#RuleCode
1Strict JSON with exactly _type, subject, predicateType, predicatestatement_json_invalid, statement_json_duplicate_key, statement_json_number, statement_fields
2_type is https://in-toto.io/Statement/v1statement_type_wrong
3predicateType is this page's type URIstatement_predicate_type_wrong
4subject has one member with a sha256 digest onlystatement_subject_malformed
5The contract record parses under the record rulescode of the first rule broken
6The subject digest equals the SHA-256 of the record bytesstatement_subject_unbound
7The predicate equals the parsed recordstatement_predicate_differs

What a contract does not establish

A contract is a promise about how the run will be judged. It does not show that the acceptance commands test the task: adequacy reports how many generated mutants they killed, and a contract with no kill cannot support a verdict of done. It does not show that the agent obeyed it, or who sealed it.
