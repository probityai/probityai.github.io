Budget lineage, contract v1

This URI identifies version 1 of the budget-lineage record: one principal's delegation tree and every charge the accounting authority booked for the agents in it, whatever budget each charge names. A runtime that keeps a counter per flow and starts it again when a sub-agent opens a new root shows the parent a clean picture; this contract judges the whole tree instead. A record written against it carries:

"contractId": "https://probityai.github.io/agent-evidence-observer/contract/budget-lineage/v1"

The reference cases and the expected decision for each are in vectors-budget-lineage in the agent-evidence-vectors repository. A reader refuses a record that omits this identifier or names another version.
