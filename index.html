Repositories and current releases

  • agent-evidence-vectors: Conformance cases and reference verifiers for signed agent evidence. Release v0.17.6; install with pip install agent-evidence-vectors==0.17.6.
  • agent-evidence-admission: OPA, Kyverno and policy-controller rules for admitting signed evidence. Release py-v0.1.0; install with pip install agent-evidence-admission==0.1.0.
  • agent-evidence-vocabulary: Versioned terms and crosswalks for evidence claims. Release v0.3.0; install with git clone --branch v0.3.0 https://github.com/probityai/agent-evidence-vocabulary.
  • dsse: Rust library to sign and verify DSSE envelopes. Release v0.1.2; install with cargo add dsse@=0.1.2.
  • jcs-admit: Rust library that checks raw JSON before RFC 8785 canonicalization. Release v0.1.1; install with cargo add jcs-admit@=0.1.1.
  • agent-evidence-observer: Records brokered file requests and reads selected delegation runs offline. No tagged release yet; the README gives source-pinned steps.
  • probity-verify: Checks supplied evidence bytes offline through claim-specific adapters. No tagged release yet; the README gives source-pinned steps.
  • agent-evidence-atlas: Maps assurance claims to evidence, with the Open Evidence Lab run register. No tagged release yet; the README gives source-pinned steps.
